## 大陆能不能直连？268ms 和 15% 丢包说明了什么

不能。这是买法国节点之前最该知道的一条。

第三方测评机构在 2026 年 5 月对法国节点做了完整的中国大陆网络测试，结果如下：

| 测试项 | 结果 |
| --- | --- |
| 中国大陆平均延迟 | 268ms |
| 中国电信 | 222ms |
| 中国联通 | 319ms |
| 中国移动 | 267ms |
| 港澳台 / 东南亚 | 235ms |
| 本地 Ping | 平均 333ms，丢包约 15% |

电信表现相对最好，222ms 仍然是跨洲延迟的量级，不适合拿来做需要实时响应的操作。联通 319ms 是三家最差。国际方向的表现反而正常，海外节点测试几乎不丢包，问题集中在中国大陆这一段。

三条路由分别是：电信从上海出口经德国法兰克福到普罗旺斯；联通从北京出口走 AS4837 到法兰克福再到普罗旺斯；移动从上海出口绕美国洛杉矶走 CMI 骨干到普罗旺斯。测评的原话是“路由不算过度绕远，但由于地理距离长，延迟仍然偏高”。

所以法国节点的正确用法是配中转。测评给出的方案是搭一台高带宽香港中转服务器，比如 500Mbps 的 CN2 线路，稳定性和延迟都会有明显改善。你如果还没有中转，先把中转的成本算进预算，别只看着 14.9 澳元。

## 常见问题

**法国 VPS 能直接在大陆用吗？**

不建议。第三方测评的中国大陆平均延迟 268ms，本地测试丢包约 15%，联通方向到 319ms。配一台香港中转之后体验会好很多，不配中转就当成一台远端机器用。

**双 ISP 和原生家宽是一回事吗？**

不完全是一回事。官方页面写的是“原生家宽 IP”，双 ISP 的说法来自第三方评测的测试结论。双 ISP 意味着这个 IP 同时挂在两家运营商的路由下，理论上可信度更高，但官方没有把它写进规格，你按原生住宅 IP 预期就行。

**500MB 内存够跑 TikTok 吗？**

够跑代理转发、脚本、账号环境这类活。这套配置的瓶颈从来不在内存，而在网络位置和 IP 属性。要在机器里跑直播编码软件，500MB 和 1 核都不够看，那种场景得换配置更高的套餐。

**支付宝能付吗？**

能，还支持信用卡和 PayPal。PayPal 需要在注册时选澳币结算，否则汇率换算可能不划算。

**年付和月付哪个划算？**

年付八折折合每月约 11.9 澳元，比月付九折的 13.41 澳元低约 11%，而且续费同价。前提是你已经确认这个节点适合自己，没试过就先月付。
